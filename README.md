# Vantage Football Analytics

By Michael Huettl.

A fantasy football analytics site. Rankings are a conclusion; the site
publishes the argument underneath them: the opportunity, efficiency and
situation behind the result, and where they disagree with the ranking.

Next.js 16 (App Router), TypeScript and Tailwind. A personal, non-commercial
portfolio project.

## Run it

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # also typechecks; a bad data edit fails here
```

`npm run build` is the check that matters.

## Deploying

The site needs a host that runs Next.js on a server. **Static hosting,
including GitHub Pages, will not work.** Six routes render on each request,
and three of them pull live data from outside sources as they do.

- **Set `NEXT_PUBLIC_SITE_URL`** to the site's full address before the first
  build. It is the only environment variable the site reads. Without it, every
  shared link shows a broken preview image.
- **Use Node 22**, and allow server functions time to wait: some request-time
  pulls take up to 30 seconds on a cold cache.
- **A GitHub Action commits to `main` about every hour** (`news.yml`). Pull
  before you push, and expect a host that deploys on push to rebuild each time.

[`docs/HANDOFF.md`](docs/HANDOFF.md) §2 has the full list.

## Where things live

| To change | Edit |
| --- | --- |
| Draft rankings | `src/data/rankings/{qb,rb,wr,te,k,dst}.json` |
| Weekly rankings | Fill the week in the workbook's Rankings sheet, then run `scripts/curated/weekly_rankings.py` |
| A player's name, team or photo | `src/data/players.json`; headshots in `public/img/headshots/` |
| A metric definition | `src/data/glossary.json` |
| Team colors | `src/data/teams.json` |
| The season's fixtures | `src/data/schedule.json`, which the live game tracker builds on |
| Position charts | Generated by the extractors in `scripts/curated/` from the analytics workbook |
| A color or font | `src/app/globals.css`, and nowhere else |
| The author credit | `src/lib/site.ts` |

Content lives in `src/data/` rather than `public/data/` on purpose: files under
`src/` are typechecked, so a stray comma fails the build with a line number
instead of shipping a broken page.

## Rules this codebase keeps

- **No React component computes a metric.** Numbers are settled in the Python
  extractors or the server-side data layer, and components only draw them (§11).
- **No NFL logos in the interface.** Teams are a color pair and an
  abbreviation (§2).
- **News is a headline, a source, a time and a link**, never article body text (§2).
- **Amber marks one focal thing per screen**, and there is no second accent
  color (§7).
- **An injury return date is reported with its source, or not at all** (§5.3).
- **American spelling and no em dashes** in anything a reader sees.
